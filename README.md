This game was built using MACOS, please using macos to run it.

I designed a yellow bird — it’s an explosive bird that can kill enemies and blast away wooden planks and steel. Steel is a new material I created; it cannot be pushed by red balls, but can only be destroyed by explosions from yellow balls. In addition, I added explosion sound effects and visual effects to the yellow bird, which automatically play when it detonates. I also implemented a camera shake effect during the explosion to make it look more realistic.ic.
